MediaExport 使用说明

简介

MediaExport 是一款自媒体数据导出工具，支持抖音、视频号、小红书三大平台。可导出创作者数据、内容分析、粉丝画像等信息。所有数据均在本地处理，不上传云端。

支持平台

  • 抖音 — 播放量数据、作品列表、账号总览、粉丝画像
  • 视频号 — 视频数据、关注者数据、来源分布、粉丝画像
  • 小红书 — 账号概览、内容分析、粉丝数据

使用方法

  1. 页面顶部显示环境检测状态（Python / Playwright / Chrome / 输出目录），点击「刷新」可重新检测。
  2. 单平台导出 — 点击对应卡片上的「导出」按钮，仅导出该平台数据。
  3. 一键导出全平台 — 点击紫色按钮，依次导出抖音、视频号、小红书全部数据。
  4. 运行日志会实时显示在下方终端区域，完成后提示「完成」。

输出文件

数据文件保存在 output/ 文件夹中，按平台和导出时间分类存放。

注意事项

  • 使用前请确保 Chrome 已安装，各平台账号已登录。
  • 导出过程中请勿关闭页面。
  • 如遇连接失败，确认「启动面板.bat」正在运行。
  • 详细说明请参阅 readme.txt。
