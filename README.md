# MediaExportTool

自媒体多平台数据导出工具：**抖音 / 视频号 / 小红书** 一键导出，并附带机器可读的数据清单。

本地运行，登录态复用，数据不出本机。

## 能导出什么

| 平台 | 数据类型 |
|---|---|
| 抖音 | 播放量数据（近30天）、作品列表、账号总览指标、粉丝画像 |
| 小红书 | 账号概览（观看/互动/涨粉/发布）、内容分析、粉丝概览、粉丝画像 |
| 视频号 | 全部视频、单篇视频、关注者数据、来源分布、粉丝画像 |

每次运行还会产出一份 `export_manifest_<平台>_<时间>.json` 数据清单，逐文件标注：

- 状态：`OK` / `OK(兜底)` / `FAIL`
- 校验结果：必备列名、最低行数
- 数据时间范围

下游做数据分析时，可以先读清单、只取可信文件，避免把"跑出来了但内容不对"的数据带进分析。

## 特点

- 网页控制面板，一键导出全部平台，进度实时显示
- 登录态独立复用，扫码一次长期有效
- 下载崩溃自动恢复：浏览器中途崩溃也能把文件收回来，不丢数据
- 页面改版自适应容错：定位带备选策略、关键页面结构带漂移告警、失败留诊断包
- 产出契约校验：列名/口径/行数不合格直接标 FAIL，不混进可用数据
- 浏览器后台最小化运行，不打断你在其他窗口的工作
- 运行日志全量保留，方便排查

## 快速开始

1. 安装 [Python 3.10+](https://www.python.org/downloads/)（安装时勾选 Add Python to PATH）
2. 安装依赖：

   ```bash
   pip install playwright openpyxl
   ```

3. 双击 `启动面板.bat`，浏览器会自动打开控制面板（也可手动访问 http://127.0.0.1:8766）
4. 首次导出时按提示扫码登录各平台，之后自动复用登录态

> 工具驱动的是你电脑上安装的 Chrome（或自动检测 Edge），不需要额外下载浏览器内核。

## 配置

编辑 `config.json` 可修改：

- Chrome 调试端口（视频号）
- 各平台登录 Profile 名称
- 输出目录
